# TripPilot — Travel Planner ✈️

TripPilot is an interactive travel planning website built with **HTML, CSS, and JavaScript**.

It helps users discover destinations, plan trips, choose transportation, create itineraries, find stays, manage budgets, prepare packing lists, and save trips.

## Features

* 🌍 Discover travel destinations
* 🗺️ Plan trips with dates and travelers
* ✈️ Flight, Train, Bus, Cab, Metro, Auto and Ferry options
* 📅 Create day-by-day itineraries
* 🏨 Stay Finder
* 💰 Trip budget calculator
* 🎒 Packing checklist
* 🧳 Save and manage trips
* ⚙️ Travel preferences and settings
* 💾 LocalStorage for saving data
* 📱 Responsive design
* 🌐 GitHub Pages ready

## Technologies

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Unsplash Images

## Note

TripPilot runs completely in the browser. It does **not** use live booking, payment, airline, railway, or hotel APIs. Transport and budget values are planning estimates.
